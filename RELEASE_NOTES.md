# Standby Clock by YAHBALLON v0.1.2

The first **standalone PS5 homebrew release** of Standby Clock.

## Included

- New AI-generated **neon-red Standby Clock logo** with the outer circular border removed, now used for **sce_sys/icon0.png**.
- Premium README with application features and a preview screenshot in **screenshots/**.
- Native realtime digital/analog clock, day/date/calendar, 12/24h mode, adjustable foreground alarm/snooze.
- Automatic current weather using public-IP location plus Open-Meteo, 15-minute background refresh and offline cache.
- OLED burn-in risk reduction: whole-screen pixel shift, idle/night dimming, temporary black rest.
- Fixed stray AM/PM placement from v0.1.0.
- Same Title ID **PPSA99876**; preferences maintained during upgrade.

## Download / install

Download the attached **PPSA99876.zip**, extract the PPSA99876 folder, and replace the existing homebrew install via your supported PS5 installer/ShadowMountPlus.

**Limitations:** Weather location is approximate. The in-app alarm does not wake a sleeping PS5, and OLED guard cannot guarantee against burn-in. Hardware tests are still encouraged.
